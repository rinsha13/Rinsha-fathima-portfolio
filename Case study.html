01 — OVERVIEW

One portfolio.
One clear story.

The portfolio presents a designer who also builds for the web, bringing interface design and front-end development together in one digital experience.

The original website uses a dark navy canvas, cool blue accents, generous spacing and restrained motion. This case study documents those existing choices rather than introducing a new visual identity.

02 — DESIGN DIRECTION

Quiet interface.
Confident details.

01

Dark foundation

A deep navy background reduces visual noise and lets the content and blue highlights stand out.

02

Blue as a signal

Blue is reserved for names, labels, links and selected emphasis to create a consistent visual path.

03

Depth through layers

Translucent panels, subtle borders, gradients and shadows create the glass-inspired 3D hero treatment.

04

Motion with purpose

Scroll reveals, gentle floating elements and pointer tilt add feedback without changing the core layout.

04 — BUILD PROCESS

From structure
to interaction.

01
STRUCTURE

HTML sections

Semantic page areas organise the hero, about, skills, selected projects, experience and contact details.

02
VISUAL DESIGN

CSS styling system

Flexbox and CSS Grid arrange content. Spacing, rounded cards, gradients, borders and responsive type create the visual hierarchy.

03
INTERACTION

JavaScript behaviour

IntersectionObserver reveals content on scroll, pointer movement tilts the hero visual, and the mobile menu opens and closes.

04
POLISH

Responsive and motion-aware

The layout adapts for smaller screens, and the script respects the reduced-motion preference for the pointer-driven effect.
